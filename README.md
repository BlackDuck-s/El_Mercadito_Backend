# El_Mercadito
La Aplicación Web de “El mercadito” para la UAM Cuajimalpa es una plataforma digital diseñada para facilitar la compra y venta de productos dentro de la comunidad universitaria. Permitirá a usuarios (estudiantes, profesores y personal administrativo) adquirir diversos artículos como alimentos, útiles escolares, ropa, tecnología o servicios.
